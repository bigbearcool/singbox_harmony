## 尚未完成的主要事项

1. 后台稳定性：0.5.6 普通/定位任务及通知已基础验证，仍需拔线锁屏 30 分钟、整夜及耗电实测。
2. 系统后台订阅更新：登记、测试回调、共享私有文件及关闭时 HTTP 终止已通过；自然周期唤醒待长期测试。
3. 按需连接与配置 Wi-Fi 条件：0.6 已离线实现 SSID／网络类型同步；真实切网及路由／DNS 结果待真机。BSSID、进程已终止时自动拉起等完整按需能力仍未对齐。
4. 原生快捷入口与应用范围：0.6 卡片及图标快捷方式、逐应用 VPN 范围均已完成离线实现待真机；外部远程管理未开放。
5. 工具及扩展：STUN/网络质量等高级工具、完整诊断报告，以及 Tailscale/OpenVPN/OpenConnect 等其他 endpoint/service 未提供。当前接受的 endpoint 范围仍限用户态 WireGuard。
6. 已实现流程的补验：扫码、剪贴板首次授权、文件导入/导出选择器，以及真实 Wi-Fi/蜂窝切换仍有待真机验证。

系统 Always-On、开机拉起与断网保护尚无本应用的可用实现；需要按鸿蒙公共权限与实际设备能力单独评估。Apple 菜单栏、iCloud、Siri 等专属集成没有在本项目中声称已完成对应功能。

## 平台差异与尚未提供的功能

后台驻留设计与验收门槛见 [后台运行方案](background-residency.md)。0.5.6 普通/定位任务及 WorkScheduler 已基础真机验证，长期后台稳定性尚未验收。

- 公共 SDK 的 VPN 启停、路由、NetConn 绑定与 Wi-Fi 信息接口已使用。系统结束进程后，普通自签 App 不能把自己的计时器当作系统后台常驻；本版没有系统 Always-On、开机自动拉起或断网保护。
- SSID 规则只在 VPN 扩展服务存活期间监控网络。暂停状态没有 TUN；服务若被系统结束，需要重新打开 App。0.6 候选向 Go 平台接口提供配置内 SSID／网络类型匹配；真实 BSSID 尚不支持，App 暂停列表优先停止整个隧道。
- 远程配置后台自动更新通过系统 WorkScheduler 请求择机执行；不承诺强制停止后的唤醒或准点运行。
- 未开放外部远程控制面。0.6 候选提供桌面快捷方式与卡片；Apple 的菜单栏、iCloud、Siri 等尚无对应实现。
- 本轮没有加入 Tailscale、OpenVPN、OpenConnect 等其他 endpoint/service 扩展；仅新增当前实际配置需要的用户态 WireGuard，避免把未知平台能力当成可运行功能。

## 生命周期与数据保护

原生控制通过同一应用私有沙箱中的请求与结果文件传递，有请求 ID、时限和去重；不监听网络端口。分组、连接与日志快照仅在页面需要时产生，停止后不会冒充活动连接。

`CommandServer.Close()` 仅关闭订阅，不会释放正在运行的内核。本轮修正为先 `CloseService()` 释放实例，再关闭服务端、销毁系统 VPN；回归测试明确断言停止后 `Instance()` 为 nil。

导入原文件不会被改写；运行时只在内存中统一双栈 TUN、DNS 截获、底层 socket 绑定和客户端管理的日志设置。配置、索引、控制请求、选择记录与配置快照使用私有文件。节点地址、UUID、密钥及带凭据的 URL 不写入提交记录或系统生命周期日志。
